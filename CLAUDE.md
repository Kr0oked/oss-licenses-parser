## Project Overview

A Kotlin JVM library (`de.philipp-bobek:oss-licenses-parser`) that parses the two binary/text files generated by
the [OSS Licenses Gradle Plugin](https://github.com/google/play-services-plugins/tree/master/oss-licenses-plugin) for
Android apps:

- `third_party_license_metadata` — one line per library: `<offset>:<length> <libraryName>`
- `third_party_licenses` — concatenated license texts, indexed by the metadata offsets/lengths

The library is a drop-in open-source replacement for Google's closed-source `play-services-oss-licenses` display
library.

## Architecture

All library code lives in `src/main/kotlin/` under package `de.philipp_bobek.oss_licenses_parser`:

- **`OssLicensesParser`** (singleton `object`) — the sole public API. Three `@JvmStatic` methods:
    - `parseMetadata(InputStream)` — parses the metadata file, returns `List<ThirdPartyLicenseMetadata>`
    - `parseLicense(ThirdPartyLicenseMetadata, InputStream)` — seeks to the byte offset and reads `length` bytes from
      the licenses file
    - `parseAllLicenses(InputStream, InputStream)` — convenience wrapper combining the two above
- **`ThirdPartyLicenseMetadata`** — data class holding `libraryName`, `offset: Long`, `length: Int`
- **`ThirdPartyLicense`** — data class holding `libraryName` and `licenseContent: String`

The metadata line format is matched with a single regex: `^(?<offset>\d+):(?<length>\d+) (?<libraryName>.+)$`

Parsing errors surface as `IllegalArgumentException` (malformed metadata lines) or `EOFException` (truncated licenses
file).

## Publishing

The library is published to Maven Central as `de.philipp-bobek:oss-licenses-parser`. Signing is required (`signing`
plugin). The local build repository target (`build/repo/`) is used for verification before release.
